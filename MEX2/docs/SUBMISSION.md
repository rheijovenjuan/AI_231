|---|---|---:|---:|---|

### A100 training

| field | value |
|---|---|
| node / GPUs | `n003.ai.internal`, 8 × A100-SXM4-40GB, **1 GPU used per job** |
| objectives | wake: pos-weighted **BCE-with-logits**, selected by **val TPR @ FAR ≤ 0.1 %**; keyword: **multi-label BCE** (40 labels, `pos_weight = neg/pos` cap 50), selected by val intent accuracy after rule; baseline: **CE(intent) + 0.5·CE(slot)** |
| optimiser / schedule | **AdamW** (β 0.9/0.999), weight decay 0.05, **3e-3 OneCycle**, batch 256 / 256 / 512 (keyword / command / wake), bf16 autocast, grad clip 1.0 |
| steps | keyword **60 epochs** (best 47), command **60** (best 54), wake **34** run of max 40 (best 21); per-epoch curves in `output/training/history/*_history.csv` |
| final val losses | keyword **0.0366**, command **0.0434**, wake **0.0160** |
| wall-clock / seeds | retrain **~15 min** on 1 × A100 (stage table [`TRAINING.md` § 10](TRAINING.md)); seeds **1234** (training), **20260929** (data gen) |
