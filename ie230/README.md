# IE 230 — Statistical Design and Analysis for Industrial Engineering

Project proposals for **IE 230** (Prof. Eugene Rex L. Jalao, Ph.D.), 1st Semester 2026–2027.
The project is worth **30%** of the final grade; the proposal is due **19 September 2026**.

Each proposal demonstrates all four course outcomes:

- **CO1** — Sampling, estimation & hypothesis testing
- **CO2** — Simple & multiple linear regression + diagnostics
- **CO3** — Factorial design of experiments
- **CO4** — Response surface methodology (process optimization)

All datasets are **readily available and downloadable online** (no partner required).

### Which to pick?

- **Want the lowest-risk, guaranteed-sufficient project?** → Concrete (Option 1).
  Clean numeric factors, a physical response, and a natural RSM optimization objective.
- **Want it tied to your computer-vision interest?** → CV/Quality (Option 2).
  Uses objective image/signal/video quality metrics (PSNR, SSIM, VMAF) as the response
  and encoder/filter parameters as the experimental factors, with four ready variants
  (image compression, medical denoising, video streaming, signal denoising).
